# Instalación

**Configuración → Galería de plugins → Herramientas SVG → Instalar.** NOPAL clona el repositorio en `plugins/svg-toolkit/` y carga automáticamente los archivos que declara su `nopal-plugin.json`. No tiene backend, así que no hace falta reiniciar NOPAL.

:::caution README desactualizado
El README del repositorio todavía dice que, «cuando este repositorio esté publicado», hay que cambiar la entrada del catálogo a `available`. Hoy el catálogo del core **ya la tiene como disponible** con su `repo_url`; ese párrafo puede eliminarse.
:::
